# Reproducibility

Each experiment must record:

- Git commit;
- configuration;
- configuration hash;
- dataset manifest hash;
- fold;
- seed;
- runtime;
- GPU;
- package versions;
- checkpoint rule;
- output hashes;
- experiment status.

Kaggle is the compute environment.

GitHub is the authoritative reproducibility and project-state repository.

Raw medical volumes must not be committed to Git.
