# CORA-Lung Figure Policy

Every publication figure must answer a scientific question.

Requirements:

- technically meaningful title;
- bold title;
- bold axis labels;
- readable legend;
- physical units where relevant;
- high-resolution output;
- vector PDF/SVG whenever appropriate;
- PNG >= 300 DPI when raster output is necessary;
- no decorative t-SNE, attention, or saliency figure without a predefined scientific purpose.

All final figures must be reproducible from saved aggregate result files.
