# Practical Application Plan

A practical CORA-Lung application will be developed only after the scientific inference
pipeline is frozen.

Planned components:

1. CT ingestion;
2. validated preprocessing;
3. CORA-Lung inference;
4. lesion probability visualization;
5. volumetric lesion summary;
6. reliability information if experimentally supported;
7. explicit research-use disclaimer.

Application code is isolated from research experiments.
